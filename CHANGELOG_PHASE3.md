# Phase 3 — Ontology 2.0 and Semantic Evidence

## New in 8.0.0-phase3

- Six typed, scope-bound semantic objects: entities, events, measures, code sets, business concepts, and rules; CRUD and version-safe updates.
- Deterministic, repeatable Phase 3 candidate inference from the exact Phase 1 allowlisted assets.
- Immutable, versioned evidence snapshots referencing Phase 2 schema fingerprints, aggregate profiles and certified contracts. No record-level sample storage.
- Fail-closed structural trust diagnostics, blocked certification, independent reviewer and required rationales, audit trail, dependency cycle prevention.
- SME question queue and explicit review status tracking, without muting compiler diagnostics.
- Four interactive graph projections (conceptual, logical, evidence, dependency), focus and node inspection.
- Review-only versioned immutable ontology releases with digest and stale evidence blocking.
- REST endpoints and four interactive tabs in existing Semantics workspace.
- Windows-native Phase 3 acceptance script, additional integration tests and updated application version.

## Not claimed

- No production SQL compilation or Ask integration, no verified live Windows EC2/AWS run, no cross-warehouse semantic data validation.
- Chromium browser clicks and rendering were tested against FastAPI TestClient via an in-process fetch bridge. Direct HTTP navigation in Chromium was blocked by sandbox policy; run the PowerShell + browser acceptance on actual Windows.
