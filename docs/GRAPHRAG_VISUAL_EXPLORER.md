# GraphRAG Visual Explorer — 7.0

The GraphRAG engine remains GraphRAG 3.0. Version 7.0 renders the runtime graph as an Obsidian-style force-directed canvas. Nodes can be dragged; empty space pans; wheel/trackpad zooms; hover highlights connected nodes; click opens trust metadata; double-click loads a focused neighborhood. The browser payload excludes embeddings. Candidate relationships remain blocked from runtime joins until reviewed/validated.
