# Multi-turn governed analytics

A conversation keeps the previously resolved metric, dimensions, filters and time context only when those objects exist in the active runtime semantic workspace. Follow-up questions are revalidated against current security and trusted joins before SQL is compiled or executed.

Example after your own workspace has a certified metric and dimension:

1. `Show total orders this year.`
2. `Break that down by status.`
3. `What about last quarter?`

No business-specific example is bundled as semantic truth.
